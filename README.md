# ApexPlanet Data Analytics Internship – Task 4

## Data Storytelling and Statistical Validation

### Project Overview
This project analyzes sales data to identify business trends, validate a business hypothesis, and communicate findings through visualizations and a stakeholder presentation.

### Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib
- SciPy
- Microsoft PowerPoint

### Analysis Performed
- Data quality checks and missing-value analysis
- Sales analysis by product category and city
- Gender-based average sales comparison
- Welch's independent two-sample t-test
- P-value and 95% confidence interval interpretation

### Hypothesis
**Null hypothesis (H₀):** There is no statistically significant difference in average order sales between male and female customers.

**Alternative hypothesis (H₁):** There is a statistically significant difference in average order sales between male and female customers.

### Key Statistical Findings
- Test: Welch's independent two-sample t-test
- P-value: 0.4950
- Significance level: 0.05
- Result: Fail to reject the null hypothesis.

The analysis did not find a statistically significant difference in average order sales between male and female customers.

### Conclusion
The project demonstrates how statistical hypothesis testing and data visualization can support evidence-based business decisions. The findings should not be interpreted as proof that the two groups are equal.
